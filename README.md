# 🏋️ Gym Log

App web per tracciare gli allenamenti di pesistica, pensata per un tablet in orizzontale appeso in palestra.

- Nome atleta e data dell'allenamento
- Gruppi muscolari con esercizi, serie, ripetizioni e kg
- Viste **Giorno**, **Settimana** e **Mese** (con volume totale e gruppi più allenati)
- Funziona offline, i dati restano nel browser del tablet (localStorage)
- Pulsante 💾 per scaricare/caricare un backup `.json`

## Pubblicare su GitHub Pages

1. Crea un nuovo repository su GitHub (es. `gym-log`).
2. Carica `index.html` e `README.md` (Add file → Upload files).
3. Vai in **Settings → Pages**, scegli *Deploy from a branch*, branch `main`, cartella `/ (root)`, poi Save.
4. Dopo circa un minuto l'app è online su `https://TUO-UTENTE.github.io/gym-log/`.
5. Sul tablet apri il link e usa "Aggiungi a schermata Home" per averla a tutto schermo.

## Nota importante

I dati sono salvati nel browser del singolo dispositivo: usa sempre lo stesso tablet e fai ogni tanto un backup con 💾.
